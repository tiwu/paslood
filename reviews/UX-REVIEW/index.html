    Wealth Pilot — Product UI/UX & Information Architecture Review

    • Date: 2026-10-25
    • Lenses Applied: Usability Heuristics (.agents/skills/ux-heuristics), Visual Hierarchy & Dark UI (.agents/skills/refactoring-ui), Jobs-to-be-Done (.agents/skills/jobs-to-be-done)
    • Primary Sources Audited: src/wealth_pilot/delivery/web/templates/index.html (3,815 lines), src/wealth_pilot/delivery/web/i18n.py, src/wealth_pilot/cli.py
    • Target Context: Mobile-first remote access (phone over Tailscale/DDNS) + Multi-Tenant SaaS / Self-Hosted IaaS with Social Login (Google, GitHub, Meta).

    1. Executive Summary: Why the App Feels Scattered

    Wealth Pilot has strong financial calculators (Buy-Only Rebalancing, Debt vs. Invest APR comparison, Belgian 2026 Capital Gains Tax simulator, Loan Amortization estimator, Compound Trajectory), but the interface is organized around backend storage mechanisms rather than user tasks:

    1. Holdings & Assets are split across 3 different tabs:
    2. Broker holdings & bucket mapping live at the bottom of Buckets (#tab-buckets, index.html:418-447).
    3. Manual assets (Real Estate, Cash) and Mortgages live in Data & Assets (#tab-cashflow, index.html:622-684).
    4. Live broker sync (PDT OAuth/MCP) lives inside Settings (#tab-settings, index.html:815-895).
    5. "Guidance" and "AI Advisor" are competing tabs: Deterministic advice appears in Overview (L359), again in Guidance (L487), while generative advice is isolated in AI Advisor (L743).
    6. First-Run Onboarding Bug (wizardFinish): The setup wizard writes bucket targets using hardcoded IDs b-core-etf, b-conviction, b-gold, b-buffer (index.html:3708-3727), whereas ConfigRepository seeds buckets with IDs core-etf, tech-growth, commodities, cash-buffer (config_repo.py:114-146). Completing the setup wizard creates 4 duplicate buckets (8 buckets totaling 200% weight!).
    7. Mobile Navigation Friction: On phone screens, all 6 sections are hidden inside a top-right hamburger drawer (index.html:195-233), and core data views rely on 6-to-7-column horizontal-scroll tables.

    4. Heuristic & Visual Design Audit

    4.1 Nielsen Heuristic Scorecard

    Heuristic Score (1–5) Key Violations & Evidence
    1. Visibility of System Status 3/5 No global indicator of when bank CSV or PDT holdings were last synced on the Dashboard; default bunq-savings (€15,000) is silently pre-seeded (config_repo.py:178-188), making new users think demo money is real or wonder where €15k came from.
    2. Match Between System & Real World 3/5 Nav item 🏦 Data & Assets has DOM ID tab-cashflow; mixes Net Worth Balance Sheet (Real Estate, Mortgages) with Cashflow (Transactions).
    3. User Control & Freedom 2.5/5 Manual assets cannot be edited once created (only deleted, index.html:646, unlike liabilities which have an edit button); no undo on "Reset CSV Cache".
    4. Consistency & Standards 3/5 Language switcher offers EN, NL, FR, DE in the UI (index.html:174-177), while backend SUPPORTED_LANGUAGES only verify en/nl in several flows; notification alerts use browser alert()/confirm() in 11 places (L3212, L3227, L3257, L3278, L3369, L3400, L3428, L3460, L3618).
    5. Error Prevention 2/5 Setup wizard creates duplicate buckets (L3708); CSV dropzone uses file.name.toLowerCase().includes('kbc') (L3663) instead of content sniffing or an explicit selector.
    6. Recognition Rather Than Recall 2.5/5 Tax simulator requires typing ticker symbols and share counts from memory instead of selecting from loaded holdings; Buy-Only calculator shows bucket names without showing which ETF tickers belong to each bucket.

    4.2 Mobile, Visual Hierarchy & Accessibility Findings (refactoring-ui)

    • Bottom Navigation Bar Missing on Mobile: Relying on a top-right hamburger menu (#btn-mobile-menu, L195) for primary navigation on phones forces two taps in the hardest-to-reach thumb zone for every tab switch. Add a fixed 5-item bottom tab bar (sm:hidden fixed bottom-0 inset-x-0) with pb-20 on <main>.
    • Redundant Bucket Table + Meters: #tab-buckets renders a 7-column table (L390) immediately followed by #bucket-meters-container (L412) showing the same data. Merge them into responsive Bucket Cards where each card has the progress bar, target vs. actual weight, drift badge, and an expandable list of assigned holdings.
    • Tailwind Play CDN in Production: <script src="https://cdn.tailwindcss.com"></script> (L22) parses the 3,815-line DOM in the browser on every page load (~300ms+ main-thread block on mobile phones) and breaks offline PWA usage.

    5. Proposed Information Architecture (Task-Oriented Consolidation)

    Consolidate the 6 scattered tabs into 4 core task-oriented views + Settings/Account, accessible via a top segmented bar on desktop and a persistent bottom tab bar on mobile:

    flowchart TD
    AUTH["Sign In Screen\n(Google / GitHub / Meta / Local Passphrase)"] --> ONBOARD{"First Login\nfor Tenant?"}
    ONBOARD -->|Yes| WIZ["3-Step Setup Wizard\n(1. Connect PDT or Upload CSV -> 2. Confirm Bucket Targets -> 3. Tax Defaults)"]
    ONBOARD -->|No| APP["Wealth Pilot App Shell\n(Header: Sync Status + Account Menu | Mobile: Bottom Tab Bar)"]

    APP --> T1["1. 📊 Overview\n- Net Worth KPIs (with Liquid-Only pill toggle)\n- Allocation Donut + 30Y Trajectory\n- FI Milestones Bar\n- Top 3 Action Alerts"]
    APP --> T2["2. 🪣 Portfolio & Buckets\n- Unified Bucket Cards (Progress + Drift + Assigned Tickers)\n- All Assets (Broker + Real Estate + Cash) & Liabilities (Mortgages)\n- 1-Tap PDT Sync & + Add Asset / Loan"]
    APP --> T3["3. 🧭 Plan & Optimize\n- Smart Buy-Only Rebalancing Calculator (calling Backend UseCase)\n- Debt Payoff vs. Invest Priority Queue\n- Belgian 2026 CGT Simulator (with Holding Selector Dropdown)\n- Contextual 'Ask AI Advisor' Drawer/Panel"]
    APP --> T4["4. 💳 Cashflow & Import\n- Monthly Income / Expenses / Savings Rate Summary\n- Bank & Portfolio CSV Import (auto-detect content, not filename)\n- Transactions Ledger & Rule Categorizer"]
    APP --> T5["5. ⚙️ Account & Settings\n- User Profile, Connected OAuth Providers & Household Members\n- Server-Side AI Provider & Encrypted Key Vault\n- Broker / MCP Connections\n- Encrypted Backup Export/Restore & GDPR Delete Account"]
